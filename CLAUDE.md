## Project

Arcade Vault ("Es una plataforma para jugar online y competir por la mayor cantidad de puntos.") — an online arcade platform where users play games and compete for high scores. Currently a fresh `create-next-app` scaffold (App Router, TypeScript, Tailwind CSS v4) with no custom routes or business logic yet — only the default `app/page.tsx` / `app/layout.tsx`.

## Spec Driven Design

Per `README.md`, this project follows spec-driven development using `/spec` and `/spec-impl`, based on practices from https://github.com/Klerith/fernando-skills, installed via:

```bash
npx skills@latest add Klerith/fernando-skills
```

When implementing features, check whether `/spec` and `/spec-impl` (or their skill files) are present before diving straight into code — the intended workflow is to write a spec first, then implement against it.

## Architecture notes

- **Path alias**: `@/*` maps to the repo root (`tsconfig.json`).
- **Styling**: Tailwind CSS v4 via the `@tailwindcss/postcss` plugin (`postcss.config.mjs`) — no separate `tailwind.config.*`; theme/tokens live in `app/globals.css`.
- **Fonts**: Geist Sans/Mono loaded via `next/font/google` and exposed as CSS variables (`--font-geist-sans`, `--font-geist-mono`) in `app/layout.tsx`.
- **Linting**: flat ESLint config composed from `eslint-config-next` (`core-web-vitals` + `typescript` rulesets).
